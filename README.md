# Skyline Duel

A small, standalone HTML5 arcade-fighting prototype with original vector-drawn
characters. No build tools or dependencies are required.

## Run it

Open `index.html` in a modern browser, or serve the project directory locally:

```sh
python3 -m http.server 8000
```

Then visit <http://localhost:8000>.

## Controls

- **A / D** — move left / right
- **W** — jump
- **F** — strike
- **R** or **Restart round** — reset the match

Touch controls are available below the arena on small screens. Astra is controlled
by the player; Bront is a simple CPU opponent.
